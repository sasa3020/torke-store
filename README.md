# 🛍️ متجر تورك | Torke Store

منصة تجارة إلكترونية متكاملة وحديثة مخصصة لطلاب الثانوية العامة وأولياء الأمور لشراء الكتب المدرسية، ملازم المراجعة، كشاكيل التمارين، وأكواد كبار المدرسين، مع لوحة تحكم إدارية متطورة ونظام تخصيص ديناميكي.

---

## 🚀 المميزات الرئيسية (Key Features)

- ⚡ **أداء فائق وسرعة صاروخية**: مبني بأحدث إصدارات **React 18** و **Vite** و **Tailwind CSS**.
- 📱 **تصميم متجاوب بالكامل (Mobile-First)**: واجهة عربية أصيلة معمارية (RTL) متوافقة مع كل الشاشات والهواتف.
- 🎨 **نظام تخصيص المتجر (Theme Studio)**: إمكانية تغيير الألوان، الخطوط، اسم المتجر، وأيقونات الشعار مباشرة وحفظها تلقائياً.
- 🛒 **سلة تسوق ذكية**: حساب الإجمالي والشحن فوريًا، خيارات استلام، وتجربة شراء سلسة.
- 🛠️ **لوحة تحكم إدارية متكاملة (`/admin`)**:
  - لوحة إحصائيات وتقارير المبيعات
  - إدارة الطلبات وتحديث حالاتها
  - إدارة المنتجات وإضافتها وتعديل أسعارها
  - إدارة فريق العمل والصلاحيات
- 🌐 **جاهز للنشر على GitHub Pages**: يحتوي على إعدادات الـ Base المسبي وتكوين الـ GitHub Actions للنشر الآلي.

---

## 🛠️ متطلبات التشغيل المحلي (Local Development)

1. تأكد من تثبيت [Node.js](https://nodejs.org/) على جهازك (الإصدار 18 أو أحدث).
2. تشغيل الأوامر التالية في مجلد المشروع:

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة النهائية للإنتاج
npm run build

# معاينة النسخة النهائية
npm run preview
```

أو يمكنك النقر المزدوج على ملف `تشغيل_المتجر.bat` للتشغيل المباشر بنقرة واحدة!

## 📤 طريقة رفع المشروع وتفعيله على GitHub

### 1️⃣ الخطوة الأولى: إنشاء مستودع جديد على GitHub
1. ادخل على حسابك في [GitHub](https://github.com/).
2. اضغط على الزر الأخضر **New** لإنشاء مستودع جديد (Repository).
3. اختر اسمًا للمستودع (مثلاً: `torke-store`).
4. اجعل المستودع **Public** ثم اضغط **Create repository**.

---

### 2️⃣ الخطوة الثانية: رفع الملفات

#### الخيار (أ) - باستخدام أوامر Git (الأسهل والأسرع للمطورين):
افتح موجه الأوامر في مجلد المشروع ونفّذ:
```bash
git init
git add .
git commit -m "Initial commit - Torke Store ready for GitHub"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
*(استبدل `USERNAME` باسم حسابك و `REPO_NAME` باسم المستودع)*

#### الخيار (ب) - باستخدام برنامج GitHub Desktop:
1. حمّل برنامج [GitHub Desktop](https://desktop.github.com/).
2. اختر **File** -> **Add Local Repository** وحدد مجلد المشروع هذا.
3. اضغط **Publish repository** إلى حسابك.

---

### 3️⃣ الخطوة الثالثة: تفعيل الموقع مجاناً على GitHub Pages 🌐
المشروع مجهز مسبقاً بملف عمل آلي (`.github/workflows/deploy.yml`):

1. في صفحة المستودع على GitHub، اضغط على تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية، اختر **Pages**.
3. تحت قسم **Build and deployment** -> **Source**:
   - اختر **GitHub Actions**.
4. سيقوم GitHub تلقائياً ببناء المشروع ونشره خلال ثوانٍ!
5. ستظهر لك رابط الموقع الحي مثل:
   `https://YOUR_USERNAME.github.io/torke-store/`

## 📂 بنية المشروع (Project Architecture)

```
torke-store/
├── .github/
│   └── workflows/
│       └── deploy.yml        # مسار النشر الآلي لـ GitHub Pages
├── public/
│   ├── .nojekyll             # منع Jekyll لتجاوز قيود الملفات
│   ├── 404.html              # إعادة التوجيه التلقائي للمسارات
│   └── _redirects            # التوافق مع Netlify و Cloudflare
├── src/
│   ├── components/           # المكونات الأساسية (الهيدر، الفوتر، السلة، البطاقات...)
│   ├── context/              # حالة المتجر العامة (StoreContext)
│   ├── data/                 # البيانات الأولية الافتراضية
│   ├── pages/                # صفحات المتجر (الرئيسية، المنتجات، الدفع، الحساب...)
│   │   └── admin/            # صفحات لوحة التحكم الإدارية
│   ├── App.jsx               # مسارات المتجر والتنقل
│   └── main.jsx              # نقطة البداية (HashRouter مهيأ لـ GitHub Pages)
├── index.html                # ملف الـ HTML الأساسي
├── vite.config.js            # إعدادات Vite ومسار Base النسبي
└── package.json              # التبعيات والسكربتات
```
